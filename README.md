# Colorized-LiDAR Conditioned Video Diffusion — project page

Self-contained static project page (no external assets, no build step).

- `index.html` — the page. Open it directly in a browser, or serve the folder with any static server.
- `static/css/index.css`, `static/js/index.js` — styling and viewport-aware video autoplay.
- `static/videos/` — 20 H.264 MP4 demos (GT | colorized-LiDAR conditioning | prediction), 12 fps, 81 frames.
- `static/images/` — poster frames for each video, the loss/throughput plot and paper-ready contact sheets (`progression-sample*.png`, `step0-lidar-vs-gt.png`).

Authorship: Waymo World Modeling Team; project lead and major contributor: Zelin Zhao.

Layout follows the Academic Project Page Template (https://github.com/eliahuhorwitz/Academic-project-page-template, CC BY-SA 4.0),
re-implemented with a local stylesheet so the bundle has no CDN dependencies.
